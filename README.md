# AutoClean---MultiOne
Auto limpeza de cache dentro da plataforma de atendimento MultiOne

- Realiza uma limpeza de cache
- Atualiza a tela
- Reloga novamente com usuário e senha

Ideia foi feita para ajudar o suporte e o desenvolvimento da plataforma. Onde a limpeza de cache, pode ajudar com a normalidade dos processos da plataforma.
